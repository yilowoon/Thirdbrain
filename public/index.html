노드를 선택하세요

바깥 고리는 진단(문제), 안쪽은 공약(해법)입니다. 클릭하면 무엇이 무엇을 해소하는지, 어떤 시민 신호가 걸려 있는지 여기에 표시됩니다.

  • 링 개수 = 계층 — 진단은 링+채움, 공약은 이중 링, 영역·시는 삼중 동심원
  • 채움이 가득 찬 링 = 위험 (실버)
  • 크기 = 우선순위 — 잔여위험 + 구조적 심각도 + 파급
  • 색 = 연결 얽힘도 — 그레이(적음) → 골드(많음)
  • 선은 누르기 전까지 그리지 않습니다. 노드를 누르면 연결이 블루로 점등
  • 드래그로 이동, 휠로 확대, 빈 곳 클릭으로 초점 해제

시민 신호 입력

민원·현장 위기·언론 보도를 진단 항목에 연결합니다. 연결 즉시 해당 노드가 커지고, 대응 공약이 없으면 붉게 전환됩니다.

신규 정책 입력

정책 니즈를 저장하고, 97개 진단과 대조해 연결 지점을 자동으로 찾아 망에 편입합니다. 자동 판정이 애매하면 저장만 하고 Claude Code 가 처리하도록 넘깁니다.

입력 후 눌러 연결 지점을 확인하세요.
