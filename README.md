# ThirdBrain — 세종시 12대 섹터 진단·공약 네트워크

「세종시 진단 12대 섹터 정리」의 **97개 진단**과 브리핑 계획표·공약자료집의 **54개 공약**을
하나의 망으로 잇고, **뇌(top view) 형태**로 배치한다.

```
피질(바깥)  ● 진단 97   문제는 표면에 드러난다
백질(안쪽)  ■ 공약 54   해법은 안에서 연결한다
좌반구      물적 기반  — 경제·과학기술·도시인프라·환경·농업·안전
우반구      사람과 위상 — 행정수도·문화·국제화·교육·복지·보건
중심        세종시. 모든 축이 여기로 수렴한다.
```

노드를 선택하면 연결된 노드가 **홉 거리 순서로 차례차례 점등**된다(신경 발화).
1홉 0.105초, 2홉 0.210초… 순으로 빛이 번지고, 선을 따라 전류가 흐른다.

## 정밀 진단 — 97개 전수 채점

세종시는 특정 분야가 아니라 **전 분야가 동시에 취약한 구조**다.
그 판단을 주장이 아니라 수치로 만들기 위해 4축 평가모델로 97개 진단을 전수 채점했다.

### 4축 (각 1~5점)

| 축 | 묻는 것 | 가중 |
|---|---|---|
| **구조성** | 단년도 정책으로 해소되지 않는 구조적 결손인가 | 30% |
| **체감도** | 시민 생활에 직접·즉시 닿는가 | 25% |
| **악화성** | 방치하면 스스로 악화되고 다른 영역으로 번지는가 | 25% |
| **권한 결여** | 해법이 시 권한 밖(중앙·국회·타기관)에 있는가 | 20% |

**구조적 심각도 = 가중합 × 20** (0~100)

### 잔여위험 — 대응을 감안하고도 남는 위험

```
잔여위험 = 구조적 심각도 × (1 − 대응 감쇄) + 현장 신호 가산
대응 감쇄 : 공약 0건 0% · 1건 18% · 2건 30% · 3건 이상 38%
신호 가산 : min(12, 신호부하 × 0.6)
```

공약 하나가 구조적 문제를 다 없애지는 못한다는 전제를 감쇄율에 반영했다.

| 상태 | 잔여위험 | 색 |
|---|---|---|
| **위험** | 72 이상 | 적색 `#d03b3b` |
| **경계** | 58~71 | 주황 `#ec835a` |
| **주의** | 44~57 | 황색 `#fab219` |
| **관리 가능** | 44 미만 | 녹색 `#0ca30c` |

## 색 규칙

색은 하나의 일만 한다. 12색을 쓰면 식별이 무너지고 위기 적색이 묻힌다.

- **색상(hue) = 4대 영역** — 색각이상·명도대비 검증 전 조합 통과
- **섹터 = 명도 단계 + 뇌 안의 위치 + 라벨**
- **모양 = 노드 종류** — 진단은 원, 공약은 사각. 색을 못 봐도 구분된다
- **붉은색 = 위험 전용** — 섹터 색에서 적색 대역을 완전히 비웠다

상태는 **색 + 기호(`● ▲ ◆ ■`) + 맥동**을 함께 쓴다. 모션을 끈 환경에서는 정지 링으로 대체된다.

| 공약명·차수·목표지표 | 브리핑 계획표, 공약자료집 | **원자료 그대로** |
